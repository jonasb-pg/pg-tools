## Offene Punkte

- Z5/Z8: Reservierte Aufträge werden ausgeschlossen; einen Weg «trotzdem vorschlagen nach Bestätigung» gibt es nicht. Die Liste `reserviert` aus `matchmaker()` zeigt die Oberfläche noch nicht an.
- H1: Ob eine PG-ID gescannt oder getippt wurde, sieht der Server nicht. Ein Tippfehler, der genau eine andere offene PG-ID trifft, startet diese; die PG-ID steht gross im Kopf der Analyse.
- N5: Gemeldet wird erst einen Tag nach der Analyse (vorher ist «steht noch im Tab Analyse» normal, weil das Return Tool von Hand nachgeführt wird).
- M5: Setzt jemand eine Analyse fort, die im anderen Tab noch läuft (Kopie unter «Pausiert»), arbeiten zwei Tabs am selben Lauf; der Server speichert ihn trotzdem nur einmal.
- Z14: Das Ricardo Tool schreibt den Status ohne die Sperre des Analyse Tools; zwischen frischem Lesen und Schreiben bleibt ein Zeitfenster von Sekundenbruchteilen.
