## Beim Einspielen

1. Code.gs, Index.html in das Apps-Script-Projekt «Umpack Tool» (Basis.gs unverändert). Version `2026-10-24.2`.
2. **Sofort danach im Editor «einrichten» ausführen.** Es ergänzt in bestehenden Tabs:
   - «Zuordnung»: Spalte **«Scan-ID»** (ohne sie lehnt `zuordnen` jeden Scan mit «Spalte «Scan-ID» fehlt … einrichten ausführen» ab; die Scans bleiben in der Schlange des Browsers und werden alle 5 s erneut versucht, nichts geht verloren).
   - «Durchgänge»: Spalten **«Verworfen am»**, **«Verworfen von»** (für den Status «Verworfen»; ohne sie scheitert «Verwerfen» laut).
   - «Einstellungen»: Erklärungen nachgeführt; «Quell-Tabs» wird auf die Vorgabe ohne «Spenden» gesetzt, falls dort noch genau die alte Vorgabe steht.
3. Neue Bereitstellung der Web-App. Scan-Handys und PCs **einmal neu laden** (alte Seiten fragen sonst weiter über `zuordnen` ab; das schreibt jetzt keine Log-Zeilen mehr, liefert aber keine Gebinde-Änderungen).
4. Gespeicherte Schlangen im Browser (`um-q-…`) bleiben gültig, der neue Server nimmt das alte Format an. Die Seiten vor dem Einspielen schicken bei Barcode-Scans schon eine Scan-Kennung mit, die der alte Server nur im Cache hatte. Der neue Server kennt sie darum nicht; hat die gültige Zeile des Wunsch-Stücks keine «Scan-ID» (vom alten Server), gilt die Wunsch-Regel (gleiches Gebinde, gleiches Kürzel = schon gespeichert), so bucht ein wiederholter alter Scan kein zweites Stück (Nach-Review N2). Ganz alte Seiten ohne Kennung: immer Wunsch-Regel. Neu im Browser-Speicher: `um-ng-<Durchgang>` (rote Liste).
5. Keine neuen Berechtigungen: `Session.getEffectiveUser` braucht dieselbe Freigabe wie `getActiveUser`, `insertRowsAfter`/`insertColumnsAfter` dieselbe wie das bisherige Schreiben.

## Von Hand zu tun

- Nach «einrichten» im Tab «Einstellungen» prüfen: «Admins» ist leer (bestehende Datenbank) → nur das Konto, unter dem das Tool läuft (Jonas), darf wieder öffnen und Durchgänge mit Scans verwerfen. Wer das sonst noch darf, dort eintragen.
- «Quell-Tabs» prüfen, falls jemand den Wert schon von Hand geändert hat (dann ersetzt «einrichten» ihn nicht).
- Kamera auf einem echten Handy kurz ausprobieren: eine Puppe länger im Bild (ein Stück), EAN und PG-Etikett im Bild (ein Stück), zwei verschiedene Stücke kurz nacheinander (das zweite kommt nach 1,5 s, solange es im Bild bleibt), zwei gleiche Puppen (dieselbe EAN) nacheinander: die zweite erst, wenn die EAN 3 s aus dem Bild war, dann gelb «zweites Stück derselben EAN».
- Hand-Scanner am PC einmal ins Kürzel- und ins Preisfeld scannen: Der Code muss im Scanfeld landen, das Feld behält seinen Wert. Scanner, die langsamer als 50 ms pro Zeichen tippen, werden nicht erkannt (dann landet der Code wie bisher im Feld; der Preis wird trotzdem abgelehnt).

## Offene Punkte und Restrisiken

- Ein PG-Etikett, das nach einem EAN-Scan desselben Stücks bewusst aus dem Bild genommen und mehr als 1 s später erneut gezeigt wird, während die EAN nicht mehr im Bild ist, zählt als neues Stück (die Kamera kann ein Stück nicht wiedererkennen). Das Tool zeigt dann ✅ für die zweite PG-ID; es bleibt die Kontrolle beim Abschluss.
- Eine EAN, die ein Stück gebucht hat und mindestens 3 s nicht erkannt wurde, bucht beim nächsten Erkennen ein weiteres freies Stück derselben EAN (gelb mit «zweites Stück derselben EAN»). Bei gleichen Stücken ist das gewollt; liegt dasselbe Stück so lange schlecht im Bild, ist der Hinweis das Signal zum Prüfen (Nach-Review N1).
- Wer gleiche Stücke (dieselbe EAN) schnell wechselt, ohne dass die EAN 3 s aus dem Bild ist, hört für das zweite Stück keinen neuen Ton; die Leiste zeigt weiter das ✅ des ersten Stücks.
- Nach einer Ablehnung (z.B. «PG-ID-Etikett scannen») gibt es keine Sperre für andere Codes, damit das verlangte Etikett sofort zählt; der abgelehnte Code selbst piept erst wieder, wenn er 1 s aus dem Bild war.
- Die rote Liste «Nicht gespeichert» liegt im Browser des Geräts (wie die Schlange), nicht im Sheet.
- Die Hand-Scanner-Erkennung arbeitet nur in der Scan-Ansicht und nicht im Gebinde-Editor (dort darf ein Lagerort-Etikett ins Feld gescannt werden).
